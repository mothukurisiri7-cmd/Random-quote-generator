# Random Quote Generator

A simple web application that generates random inspirational quotes.

## Features
- Displays random quotes
- Clean and responsive user interface
- Generates a new quote with a button click

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download the project files.
2. Open `index.html` in your browser.
3. Click the button to generate random quotes.

## Project Outcome
Built a beginner-friendly JavaScript project demonstrating DOM manipulation and event handling.
